# C++ Basics

This repository contains my C++ programs and practice problems while learning C++ and Data Structures & Algorithms (DSA).

## 📂 Programs

### 1. secondLargestnum.cpp
Finds the second largest number in an array.

### 2. frequency.cpp
Finds the frequency of elements in an array.

### 3.zeroToEnd.cpp
Move all 0s to end of element without change in array.

### 4.findMissingNum.cpp
find missing number in array.

### 5.twoSum.cpp
find first two element sum is equal to targets.

### 6. factorial.cpp
print factorial of number.

### 7. nthfibonacci.cpp
find nth fibonacci number.

### 8. palindromeCheck.cpp
check string is palindrome or not.

### 9. swapNumber.cpp
swaping two numbers.

### 10. sumOfArray.cpp
sum all elements of an array.

### 11. reverseString.cpp
reverse string without using reverse().

### 12. reverseArray.cpp
reverse array by using pointer.

### 13. firstNonRepeating.cpp
find first non-repeating element in an array.

### 14. removeDuplicates.cpp
remove duplicates without using another array.
